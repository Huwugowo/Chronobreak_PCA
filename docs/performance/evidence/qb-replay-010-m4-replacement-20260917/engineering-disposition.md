The first four engineering questions therefore have no evidence-backed
correctness, reliability, or unbounded-resource defect that warrants a
production change. The cancellation evidence is deliberately explicit about
the telemetry boundary: the server observed an incomplete body, while the
child's status is only indirectly constrained by the probe implementation.
