# Development icon fixtures

Small Data Dragon 16.18.1 icon subset copied from the existing local cache for the
development mock games and roster. Artwork belongs to Riot Games. These are
presentation fixtures, not authoritative League data or a full patch cache.

Files intentionally use the same extensionless `kind/display-name` URLs as the
desktop asset server. Champion and spell names preserve their displayed casing.
No network access or user cache is needed to use this preview.
